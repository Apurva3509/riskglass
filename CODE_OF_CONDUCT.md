# Community code of conduct

RiskGlass is built through curious, respectful technical collaboration.
Participants are expected to discuss ideas and evidence without attacking
people, respect privacy, welcome different experience levels, and avoid
harassment or discriminatory behavior.

Maintainers may edit or remove contributions that violate these expectations
and may restrict participation when behavior repeatedly harms the community.
Report conduct concerns privately through the repository owner's GitHub
profile. Reports will be handled as confidentially as practical.
