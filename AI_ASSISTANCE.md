# AI assistance

RiskGlass was bootstrapped with implementation assistance from OpenAI Codex.
AI-assisted changes are held to the same review, testing, security, and
licensing standards as human-written changes.

Pull requests should briefly disclose substantial AI assistance and identify
what the author verified. AI tools are not listed as Git co-authors unless the
tool provider supplies a verified GitHub identity intended for that purpose.
Invented names, email addresses, or attribution trailers are not accepted.

The person submitting a change remains responsible for its behavior and for
confirming that generated material can be distributed under this repository's
license.
